# Neuro SAN Documentation

**Neuro SAN** (Neuro AI System of Agent Networks) is an open-source framework for building
data-driven multi-agent AI systems powered by Large Language Models.

Instead of relying on a single LLM to handle complex tasks, Neuro SAN lets you break problems
into smaller pieces so that multiple specialized agents can collaborate to solve them together.

Agent networks are defined entirely in HOCON configuration files, enabling subject matter
experts -- not just programmers -- to design sophisticated multi-agent applications.

## Who Is This For?

- **New users** looking to understand multi-agent AI systems and build their first agent network
- **Developers** building production applications with custom tools and integrations
- **Domain experts** designing agent workflows without writing code
- **DevOps engineers** deploying and scaling agent services
